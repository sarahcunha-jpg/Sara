# Descrição do Projeto

O projeto PetLove Care consiste em uma landing page responsiva desenvolvida para um pet shop fictício, com o objetivo de apresentar os serviços oferecidos, fortalecer a identidade visual da marca e facilitar o contato entre clientes e empresa.

A página foi desenvolvida utilizando HTML5, CSS3 e JavaScript, aplicando conceitos vistos durante o curso de Introdução à Programação Front-End e Back-End.

Foram utilizados elementos semânticos para melhorar a organização do código, Flexbox e Grid para a construção do layout responsivo e JavaScript para realizar a validação do formulário de contato.

A identidade visual utiliza cores quentes que transmitem carinho, confiança e cuidado com os animais, além de uma tipografia moderna obtida através do Google Fonts.
